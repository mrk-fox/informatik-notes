# Datenbanken

## 1. Datenbankstrukturen

Als eine Datenbank ist eine digitale Ansammlung an Daten, also gespeicherten Informationen, die in einer bestimmten Struktur dargestellt und verwaltet wird, definiert.

Tabelle -> Relation
Datensatz in einer Tabellenzeile -> Tupel
Spaltenüberschrift -> Attribut
Werte in einer Spalte -> Attrubutenwerte
Eindeutiger Wert einer  Zeile -> Primärschlüssel
Anzahl der Tabellenzeilen -> Kardinalität der Relation

Entity-Relationship-Modell 
	-> Der Primärschlüssel wird unterstrichen
